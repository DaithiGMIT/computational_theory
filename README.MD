# Computational Theory
Repository for work done in the Computational Theory module In 4th Year Software Development in [ATU Galway](https://www.atu.ie/courses/bachelor-of-science-honours-software-development-full-time).

Repository will contain a Jupyter Notebook that stores the code required to complete all 8 set tasks.

## Tasks
1. Binary Representations
2. Hash Functions
3. SHA256
4. Prime Numbers
5. Roots
6. Proof of Work
7. Turing Machines
8. Computational Complexity

## How to Run
1. Ensure Python and pip are installed
2. Install Jupyter Notebook
3. Install dependencies
4. Clone Repo
5. Launch Notebook
