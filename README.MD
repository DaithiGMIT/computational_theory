# Computational Theory

This repository contains work completed for the *Computational Theory* module  
in the final year of the [B.Sc. in Software Development at ATU Galway](https://www.atu.ie/courses/bachelor-of-science-honours-software-development-full-time).

The main notebook (`tasks.ipynb`) implements and documents all 8 required tasks using Python and Jupyter.

---

## Tasks

1. **Binary Representations** – Bitwise operations: rotate, choose, and majority functions  
2. **Hash Functions** – Reimplement a simple C-style hash function in Python  
3. **SHA256** – Implement SHA256 padding logic with bit alignment validation  
4. **Prime Numbers** – Generate prime numbers using two different algorithms  
5. **Roots** – Generate 32-bit constants from square root fractional parts (SHA-style)  
6. **Proof of Work** – Find the word with the most leading zeros in its SHA256 binary hash  
7. **Turing Machines** – Simulate a Turing Machine that adds 1 to a binary number  
8. **Computational Complexity** – Analyze comparison counts in Bubble Sort across all permutations of `[1, 2, 3, 4, 5]`
